# Kaotik Düsler Makinesi

Deneysel ve eglenceli bir AI projesi - Terminal tabanli interaktif sanat ve dusunce deneyimleri.

## Moduller

| Modul | Aciklama |
|-------|----------|
| Evrimsel ASCII Sanat | Genetik algoritma ile benzersiz ASCII sanat eserleri uretir |
| Surreal Hikaye Ureteci | Ruya gibi, absurt hikayeler olusturur |
| Emoji Hayat Simulasyonu | Conway's Game of Life - Renkli emoji versiyonu |
| Dijital Fal Bakicisi | Mistik analiz ve kisisel kehanetler |
| Metin Senfonisi | Metni gorsel muzige donusturur |
| Dusunce Labirenti | Felsefi paradokslar ve dusunce deneyleri |

## Kurulum

```bash
# Projeyi klonla
git clone <repo-url>
cd Experiental-Fun-AI

# Calistir (Python 3.6+ gerekli)
python3 chaotic_dreams.py
```
